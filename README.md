# Claude Skills — by KJR Labs

A collection of production-ready Claude skills for developers and pharma/GxP professionals.

## Skills

### `nextjs-turso-saas`
Step-by-step scaffold guide for spinning up a production-ready SaaS web app using Next.js 14+ (App Router), Turso (edge SQLite), Drizzle ORM, Tailwind CSS, shadcn/ui, and TypeScript strict mode.

**Best for:** Indie developers, SaaS founders, internal tool builders

---

### `gamp5-risk-assessment`
Generates a professional, GMP-compliant FMEA-based Quality Risk Assessment document as a formatted Word (.docx) file. Fully aligned with ISPE GAMP 5 Second Edition (2022), ICH Q9, and EU Annex 11.

Covers all GAMP software categories (Cat 1, 3, 4, 5) and all major system types:
- LIMS, ERP, SCADA, MES, DCS
- Laboratory equipment and instruments
- Custom in-house applications

Includes a pre-built function library with typical failure modes per system type, and a full regulatory citation reference (21 CFR Part 11, EU Annex 11, ICH Q9, GLP, GCP, GDP, ISO 27001).

**Best for:** Pharma QA/validation professionals, CSV consultants, GxP system owners

## Installation

### Claude.ai (Web)
Download the `.skill` file from the [Releases](https://github.com/KshitijKoranne/Claude-skills/releases) page and install via Claude settings.

### Claude Code (CLI)
```bash
# Add this repo as a marketplace
/plugin marketplace add KshitijKoranne/Claude-skills

# Or install manually — copy skill folder to:
~/.claude/skills/
```

# Claude Skills — by KJR Labs

A collection of Claude skills for developers and builders.

## Skills

### `nextjs-turso-saas`
Step-by-step scaffold guide for spinning up a production-ready SaaS web app using Next.js 14+ (App Router), Turso, Drizzle ORM, Tailwind CSS, shadcn/ui, and TypeScript strict mode.

## Installation

In Claude Code, run:
```
/skill install <skill-folder>
```

Or copy the skill folder into `~/.claude/skills/` and Claude picks it up automatically.
